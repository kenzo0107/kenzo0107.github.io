## Overview

<p>When you have configured LB logs to be stored in S3 on AWS,
and you want to collect all the logs from the time range when an incident occurred,
I use awscli to retrieve the logs in bulk.</p>

<p>I've summarized the procedure for that as a memo.</p>

<!-- more -->

## Prerequisites

<ul>
<li>Install awscli</li>
</ul>


<p>The execution environment for this case is as follows.</p>

<pre class="code" data-lang="" data-unlink>macOS%$ sw_vers

macOS%$ aws --version

## Downloading the Log Files

<p>Example) Download the ALB log files for the 2 PM hour on September 12, 2018</p>

<pre class="code" data-lang="" data-unlink>// Download the log files for the 2 PM hour on September 12, 2018
macOS%$ aws s3 --profile &lt;profile&gt; cp s3://&lt;log bucket name&gt;/&lt;lb name&gt;/AWSLogs/123456789012/elasticloadbalancing/ap-northeast-1/2018/09/12/ . --recursive --exclude &#34;*&#34; --include &#34;*20180912T05*&#34;

// Decompress the log files
gunzip *.gz

// Combine the logs into a single file
cat *.log &gt; all.log

// Collect entries with an HTTP code of 50x into 50x.log
awk '{if($9 ~ 50) print $0}' all.log &gt; 50x.log</pre>


<p>`--profile &lt;profile&gt;` is the setting used when you have configured it with `aws configure --profile &lt;profile&gt;`.<br/>
If you use the default, specifying `--profile &lt;profile&gt;` is not necessary.</p>

<p>That's all.</p>
