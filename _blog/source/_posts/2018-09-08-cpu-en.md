<p>Just a memo for myself.</p>

<p>When a process hasn't been restarted in a long time, restarting it makes me a little nervous, so I want to know roughly how long it has been running.<br/>
With that in mind, I use the following command to check.</p>

<!-- more -->

<pre class="code" data-lang="" data-unlink>$ ps -eo pid,comm,etime,time  | grep node
  591 node            51-20:47:21 00:01:54
 2255 node            23-18:07:58 00:01:18</pre>


<table>
<thead>
<tr>
<th>OPTION</th>
<th>Explain</th>
</tr>
</thead>
<tbody>
<tr>
<td>pid</td>
<td>Process ID</td>
</tr>
<tr>
<td>comm</td>
<td>Command</td>
</tr>
<tr>
<td>etime</td>
<td>Elapsed time since the process started</td>
</tr>
<tr>
<td>time</td>
<td>CPU usage time</td>
</tr>
</tbody>
</table>


<p>Of course you can also grasp how heavily the CPU is being used, so it comes in handy for all sorts of things.</p>
