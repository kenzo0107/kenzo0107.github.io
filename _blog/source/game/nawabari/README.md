# ナワバリバトル

スプラトゥーン風の陣地取りゲームです。コンピュータと対戦して、より多くの陣地を塗りましょう！

## 遊び方

1. **セットアップ**
```bash
npm install
npm run build
```

2. **ゲーム起動**
`index.html` をブラウザで開きます。

3. **操作方法**
- **移動**: WASDキー または 矢印キー
- **ゲーム開始**: 「ゲーム開始」ボタンをクリック
- **リセット**: 「リセット」ボタンで最初からやり直し

## ルール

- プレイヤー（青）とコンピュータ（赤）が移動して陣地を塗り合います
- 移動した場所が自動的に自分の色に塗られます
- 制限時間は60秒
- 時間終了時により多くの陣地を塗った方が勝ちです

## 開発

TypeScriptの変更を監視してビルド:
```bash
npm run watch
```

## 技術スタック

- TypeScript
- HTML5 Canvas
- CSS3
