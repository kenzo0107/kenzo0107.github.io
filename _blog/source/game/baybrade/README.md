# ベイブレードバトルゲーム

3D物理演算を使用したリアルタイムベイブレードバトルゲーム

## 技術スタック

- **Three.js**: 3Dグラフィックスレンダリング
- **Cannon-es**: リアルタイム物理演算
- **TypeScript**: 型安全な開発
- **Vite**: 高速ビルドツール

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build
```

## 機能

### 実装済み
- ✅ 3Dグラフィックス表示
- ✅ リアルタイム物理演算
- ✅ 4種類のベイブレードタイプ（アタック、ディフェンス、スタミナ、バランス）
- ✅ 衝突判定とダメージ計算
- ✅ RPM（回転数）計算
- ✅ HP管理
- ✅ すり鉢状のスタジアム

### ベイブレードタイプ

1. **アタックタイプ**: 高攻撃力、低防御・持久力
2. **ディフェンスタイプ**: 高防御力、重量あり
3. **スタミナタイプ**: 長時間回転、低摩擦
4. **バランスタイプ**: 全パラメータ平均的

## 操作方法

1. 右側のパネルからベイブレードタイプを選択
2. 「バトル開始」ボタンをクリック
3. マウスドラッグでカメラ回転
4. マウスホイールでズーム

## ゲームルール

- 各ベイブレードは初期HP 100でスタート
- 衝突時に互いにダメージを与える
- RPMが低下するとHPも減少
- RPMが50未満になるか、HPが0になると敗北
