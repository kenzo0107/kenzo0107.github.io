# Pilot Wings Game

パイロットウイングス風の3Dフライトシミュレーションゲーム

## 技術スタック

- Three.js: 3Dグラフィックス
- TypeScript: 型安全な開発
- Vite: 高速な開発サーバー

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開く

## 操作方法

- **W/S**: ピッチ（機首上げ/下げ）
- **A/D**: ロール（左右旋回）
- **Q/E**: ヨー（機首左右）
- **↑/↓**: スロットル（速度調整）

## 実装済み機能

- [x] 基本的な飛行機の操作
- [x] 物理演算（重力、揚力、抗力）
- [x] カメラ追従
