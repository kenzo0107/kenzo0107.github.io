# 3D Basketball Game

Three.jsとCannon.jsを使用した3Dバスケットボールゲーム

## 機能

- 4vs4の対戦形式
- 3種類のシュート（3ポイント、ダンク、通常シュート）
- 物理演算によるリアルなボールの動き
- AIによる自動プレイ

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build
```

## 操作方法

### キーボード
- `W/A/S/D`: プレイヤー移動
- `Space`: ジャンプ
- `E`: シュート
- `Shift`: ダッシュ

### マウス
- 移動: カメラ回転
- ホイール: ズーム

## シュート種類

1. **3ポイントシュート**: 3ポイントライン外（6.75m以上）から - 3ポイント
2. **ダンクシュート**: ゴール直下でジャンプ中 - 2ポイント
3. **通常シュート**: フリースローライン内から - 1ポイント

## 技術スタック

- Three.js: 3Dレンダリング
- Cannon-es: 物理エンジン
- TypeScript: 型安全性
- Vite: ビルドツール
