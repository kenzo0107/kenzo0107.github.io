# ⚽ サッカー スローイン ゲーム 3D

サッカーのスローインでボールをどこまで飛ばせるかチャレンジする3Dゲームです。

## 🎮 遊び方

1. **スタートボタン**をクリックしてゲームを開始
2. パワーゲージが左右に動くので、好きなタイミングで**キャンバスをクリック**してパワーを決定
3. ボールが飛んで、飛距離が表示されます
4. ベストスコアは自動的に保存されます

## 🚀 起動方法

```bash
# ブラウザでindex.htmlを開く
open index.html
```

または、シンプルなHTTPサーバーを起動:

```bash
# Python 3を使用
python -m http.server 8000

# ブラウザで http://localhost:8000 を開く
```

## 🎯 ゲーム機能

- ✅ **フル3Dグラフィックス**: Three.jsによるリアルな3D表現
- ✅ **パワーゲージシステム**: 0-100%のタイミングゲーム
- ✅ **物理演算**: リアルな放物線運動とボール回転
- ✅ **飛距離計算**: メートル単位で正確に計測
- ✅ **ベストスコア記録**: localStorage使用
- ✅ **影とライティング**: 臨場感のある影とライト効果
- ✅ **カメラワーク**: ボールを追従するダイナミックなカメラ
- ✅ **レスポンシブデザイン**: 画面サイズに自動対応

## 🛠️ 技術スタック

- **Three.js r128**: 3Dグラフィックスエンジン
- **HTML5**: 構造とレイアウト
- **CSS3**: スタイリングとUI
- **Vanilla JavaScript**: ゲームロジック

## 💡 カスタマイズ

`game.js`の以下の定数を変更することで、ゲームバランスを調整できます:

```javascript
const GRAVITY = 0.02;        // 重力（大きいほど早く落下）
const MAX_POWER = 1.2;       // 最大パワー（大きいほど遠くまで飛ぶ）
const FIELD_LENGTH = 80;     // フィールドの長さ
```

カメラ位置の調整（`initThreeJS`関数内）:

```javascript
camera.position.set(-5, 8, 15);  // x, y, z座標
camera.lookAt(15, 0, 0);         // 注視点
```
