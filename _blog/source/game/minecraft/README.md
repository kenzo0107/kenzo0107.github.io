# Ito2 - マインクラフト風3Dボクセルゲーム

TypeScript + Three.jsで構築された3Dボクセルスタイルのゲームです。

## 技術スタック

- TypeScript
- Three.js
- Vite

## 開発環境構築

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build

# プレビュー
npm run preview
```
