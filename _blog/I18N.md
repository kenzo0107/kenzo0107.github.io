# 記事の日本語 / 英語 切り替え（i18n）

「翻訳がある記事だけ言語スイッチャーを表示する」方式。既存の日本語記事はそのままで、
英語版を用意したペアにだけヘッダーに `日本語 / English` のリンクが出ます。

## 仕組み

`themes/icarus/layout/common/navbar.jsx` が、表示中の記事の `translation_id` と同じ
`translation_id` を持つ記事 / ページを `site.posts` / `site.pages` から探し、複数言語が
揃っている場合だけ言語スイッチャーを描画します（1言語しか無ければ非表示）。

## 記事の書き方

日本語版（既存記事に追記）:

```yaml
---
title: タイトル
date: 2026-06-12
lang: ja
translation_id: aws-cost-optimization   # ペアで共通の任意の一意ID
---
```

英語版（新規ファイル。例: `source/_posts/2026-06-12-aws-cost-optimization-en.md`）:

```yaml
---
title: AWS Cost Optimization
date: 2026-06-12
lang: en
translation_id: aws-cost-optimization   # 日本語版と同じ ID
permalink: en/2026/06/12/aws-cost-optimization/   # 任意。URL を分けたい場合
---
```

- `lang` 未設定の記事は `ja` 扱い。
- `translation_id` が一致する記事が 2 つ以上あると、その記事のヘッダーに言語リンクが出ます。
- 対応言語ラベルは `navbar.jsx` の `LANGUAGE_LABELS`（`ja` → 日本語 / `en` → English）で定義。
  言語を増やす場合はここに追記します。

## 備考

UI 文言（テーマのラベル等）は Icarus の言語ファイル `themes/icarus/languages/*.yml` と
`_config.yml` の `language:` で切り替わります。現状サイト全体は `language: ja`。
